# Überblick Softwaretest

Geplante Module (orientiert am ISTQB Foundation Level):

1. Grundlagen: Warum testen? Fehler, Fehlerzustand, Fehlerwirkung
2. Teststufen: Komponenten-, Integrations-, System-, Abnahmetest
3. Testarten: funktional, nicht-funktional, Regressionstest
4. Testentwurfsverfahren: Äquivalenzklassen, Grenzwertanalyse, Entscheidungstabellen, Zustandsübergänge
5. Testmanagement: Testplanung, Risiken, Metriken
6. Fehlermanagement: Fehlerbericht, Lebenszyklus eines Fehlers
